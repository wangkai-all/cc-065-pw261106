# 运单影像收件台

本地运行的运单扫描件收件与复核工具：导入扫描图片后在**浏览器本地**完成 OCR 识别（运单号、发货地、目的地、重量、日期），按字段置信度排入待复核列表；逐条对照原图定位文字区域、逐项修正，确认后生成结构化运单记录。**图片与数据不离开本机**（OCR 引擎、语言包、数据全部本地，无任何上传）。

## 功能

- **本地 OCR 收件**：tesseract.js（chi_sim + eng，PSM 11 稀疏文本模式）在浏览器内运行，引擎与语言包已内置于 `app/vendor/`，离线可用
- **置信度排序**：记录得分 = 各字段置信度最低值，待复核列表按得分升序，最可疑的优先处理
- **并排复核**：左图右字段；点击字段行在原图上高亮对应文字区域，点击图上区域反向聚焦字段；逐项修改
- **修改留痕**：每个字段保留识别原值、人工值、修改时间；处理记录（收件/判重/修正/确认）全程留痕
- **重复件识别**：单号 + 重量 + 日期一致判为重复扫描件，自动归入重复件队列（可人工恢复）；**单号相同但重量或日期不同的判为修订件，保留并提示**，不会误丢弃
- **分类队列**：模糊图像（Laplacian 方差 + OCR 平均置信双判据）、字段缺失、编号格式错误（规则：2 位字母 + 10 位数字）分别进各自队列
- **结构化输出**：确认后生成结构化运单记录，可一键导出全部记录的 JSON（含字段级审计信息）
- **演示样本**：`samples/` 内置 8 张虚构运单图（3 种版式 + 重复件 / 修订件 / 模糊件 / 缺字段件 / 格式错误件），一键载入演示完整流程

## 运行

```bash
cd /workspace
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/app/
```

打开后点击「载入演示样本」即可看到全部队列效果；或点「导入扫描图片」选择本地图片（支持多选）。

> 需要通过 HTTP 访问（不能直接双击 html 文件），因为浏览器对 file:// 下的 Web Worker / fetch 有限制。任何静态文件服务器都可以。

## 重新生成样本

```bash
python3 -m venv .venv && .venv/bin/pip install pillow
.venv/bin/python tools/generate_samples.py
```

## 测试

```bash
npm install                 # 安装 tesseract.js / playwright 等依赖
node test/run_ocr_test.mjs  # OCR 管线测试：8 个样本的字段提取、队列分类、重复/修订判定
node test/e2e_browser.mjs   # 端到端测试：无头浏览器跑完整收件-复核-确认流程（需系统字体与 chromium 运行库）
```

## 目录结构

```
app/                 前端应用（纯静态，无构建）
  index.html
  js/extract.js      字段提取 / 队列分类 / 重复判定（浏览器与 Node 共用的纯逻辑）
  js/ocr.js          OCR 引擎封装 + 图像模糊度检测
  js/store.js        localStorage 持久化
  js/app.js          界面逻辑
  vendor/            tesseract.js 运行时、wasm 内核、chi_sim/eng 语言包（本地化，不上传）
samples/             虚构运单演示图 + manifest.json（期望值与模糊度校准值）
tools/generate_samples.py   样本图生成器（Pillow）
test/                OCR 管线测试与端到端测试
```

## 设计说明

- **运单号规则**：`^[A-Z]{2}\d{10}$`，识别值归一化（去非字母数字、转大写）后校验，不符进格式错误队列
- **模糊判定**：图像下采样至宽 400 后计算灰度 Laplacian 方差，阈值 1000（清晰样本 >4500，模糊样本 <500，见 `samples/manifest.json`）；OCR 平均置信 <45 也判模糊
- **重复/修订**：以归一化单号匹配历史记录（含已确认、已修正值）；重量与日期均一致 → 重复件；任一不同 → 修订件保留
- **字段提取**：先解析行内「标签-值」段（兼容同一行多字段的表格版式），再将孤立标签行与右侧/下方文本行做空间配对（兼容输入框版式），最后按格式正则兜底
